## 📥 Como Baixar a Versão Mais Recente

Para baixar o aplicativo pronto para uso em ambiente Windows:

1. Acesse a área de **[Releases / Lançamentos](https://github.com/alissonramos22/B1UDFMANAGER-Releases/releases)**.
2. Baixe o executável da versão mais recente (ex: `SAP.B1.UDF.Manager-v1.3.0.exe`).
3. O aplicativo é **Portable** — basta dar um duplo clique para iniciar, sem necessidade de instalação complexa ou privilégios de administrador.

---

## 📌 Principais Recursos do SAP B1 UDF Manager

- **🛠️ Criador e Importador de Metadados**: Criação de Tabelas de Usuário (UDT) e Campos Customizados (UDF) via Service Layer ou importação de scripts SQL (HANA) e CSV.
- **🔄 Replicação Multi-Base**: Comparação de metadados em tempo real entre bases de dados (Homologação ➔ Produção) e replicação em lote.
- **📑 Audit Log Técnico**: Registro e histórico completo de transações em PDF (A4 Retrato) para auditorias.
- **🛡️ Licenciamento & Sessão Única**: Controle de acesso por licença com tolerância offline de até 48 horas.
- **🤖 Treinamento Guiado Interativo**: Tour dinâmico que ensina a utilizar cada recurso direto na interface.
